# GreenPavlodar AI

Карта озеленения Павлодара: парки, лесные массивы, проблемные зоны; расчёт дефицита деревьев,
подбор видов, смета и ИИ-функции на языковой модели.

## Запуск

```bash
cp .env.example .env        # по желанию впишите ANTHROPIC_API_KEY
docker compose up --build
```

Фронтенд — http://localhost:3000, API и документация — http://localhost:8000/docs.

## Что здесь настоящее ИИ, а что обычный расчёт

| Функция | Как работает |
|---|---|
| Новый объект в редакторе (`/api/v1/ai/species`) | **Языковая модель** (Groq бесплатно, любой OpenAI-совместимый сервис или Claude) подбирает значок, цвет, тип и оценивает зимостойкость для Павлодара. Ответ проверяется (формат, цвет, эмодзи). Без ключа — простые правила по ключевым словам, интерфейс об этом сообщает. |
| Заключение по зоне (`/api/v1/ai/zone-report`) | **Языковая модель** пишет текст только по посчитанным числам и допущениям. Без ключа — шаблонный текст. |
| Анализ дефицита (`/api/v1/scan`, `/analyze-zone`) | Обычный расчёт: площадь по контуру, плотность деревьев, дефицит относительно целевой плотности. Не ИИ. |
| Подбор видов (`/api/v1/recommend-plants`) | Правила и взвешенная оценка по справочнику `backend/data/plants.json`. Не ИИ. |
| Смета (`/api/v1/calculate-estimate`) | Формула с коэффициентами из `backend/config.py`. Не ИИ. |

Анализа спутниковых снимков (NDVI, засоление по съёмке) **нет**, и он больше не имитируется.
Чтобы добавить его по-настоящему, нужен источник данных (например, Sentinel-2) и отдельный модуль на backend.

## Правило «проблемной зоны»

Зона категории «Проблемная» не считается проблемной, если в радиусе 500 м (`PROBLEM_GREEN_RADIUS_M`)
от её границы есть парк или лесной массив. Для такой зоны дефицит и смета не рассчитываются,
на карте она серая, в интерфейсе указан ближайший парк/лес.

## Данные и доступ

Зоны, расставленные объекты и палитра хранятся на сервере (Postgres через `DATABASE_URL`, иначе файл).
Читать и править может любой посетитель, пока не выключено `EDITING_ENABLED=false` — тогда сайт только
для просмотра. Запись защищена номером ревизии: устаревшая вкладка не затрёт свежие данные.

## Что нужно проверить людям

* `backend/data/plants.json` перенесён из прототипа и не проверен ботаниками.
* Целевая плотность деревьев (120 на га, `TARGET_TREES_PER_HA_*`) и расценки (`COST_*`) — рабочие допущения, не нормативы.
* Количества деревьев и контуры в `frontend/src/zones.ts` — демонстрационные.

## Тесты

```bash
cd backend && python -m unittest discover -s tests -v   # расчёты и ИИ-модуль (без сети и ключа)
cd frontend && npm test                                  # геометрия
```

## Заметки по безопасности

* Ключ API хранится только на сервере (`.env`), браузер его не видит.
* Редактирование открыто без пароля — перед сдачей работы жюри выключите его (`EDITING_ENABLED=false`).
* ИИ-эндпоинты ограничены по частоте (`AI_RATE_LIMIT_PER_MIN`, по IP). За reverse-proxy ограничение нужно дополнить на уровне прокси.
* CORS разрешён только для адресов из `CORS_ORIGINS`.
* Если папки `.vs/` и `__pycache__/` уже попали в git: `git rm -r --cached .vs backend/__pycache__`.
