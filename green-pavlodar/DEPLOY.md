# Как выложить сайт, чтобы он работал без вашего ноутбука

## Главное простыми словами

**Сейчас** сайт живёт на вашем ноутбуке. Выключили ноутбук — сайта нет.

**Render** — это сервис, который даёт вам «чужой компьютер, который всегда включён и подключён к интернету».
Вы один раз отдаёте ему проект, он запускает сайт у себя и выдаёт ссылку вида `https://green-pavlodar.onrender.com`.
Дальше жюри открывает эту ссылку **с любого устройства в любое время**, а ваш ноутбук может быть выключен,
закрыт или вообще сломан. Ноутбук нужен только один раз — чтобы отправить проект.

Как идёт запрос:

```
Жюри открывает ссылку → компьютер Render запускает ваш сайт → сайт берёт данные из базы данных (тоже у Render)
```

В базе лежат ваши зоны, деревья, скамейки и урны. Поэтому они не пропадают ни при выключении ноутбука,
ни при обновлении страницы.

Что нужно:
1. **GitHub** — «склад» с вашим кодом (аккаунт у вас уже есть).
2. **Render** — «компьютер», который берёт код со склада и запускает сайт. Он же создаёт базу данных.

## Шаг 1. Загрузить проект на GitHub

Файл `Dockerfile` и `render.yaml` должны лежать **в самом корне** репозитория (не внутри вложенной папки).

1. На github.com нажмите **+ → New repository**, назовите, например, `green-pavlodar`, создайте (можно публичный).
2. Нажмите **uploading an existing file**.
3. Откройте папку проекта на компьютере (ту, где лежат `Dockerfile`, `render.yaml`, `backend`, `frontend`),
   выделите **всё содержимое** (Ctrl+A) и перетащите в окно браузера. Саму папку целиком перетаскивать не нужно.
4. Внизу нажмите **Commit changes**.

## Шаг 2. Запустить на Render

1. Откройте https://render.com → **Get Started** → **Sign in with GitHub**, разрешите доступ к репозиторию.
2. Нажмите **New + → Blueprint**, выберите репозиторий `green-pavlodar`.
3. Render прочитает файл `render.yaml` и покажет, что создаст: сайт (`green-pavlodar`) и базу (`green-pavlodar-db`).
   Нажмите **Apply** / **Deploy Blueprint**.
4. Подождите 5–15 минут: идёт первая сборка. Когда у сервиса `green-pavlodar` появится статус **Live**,
   нажмите на ссылку `https://….onrender.com` вверху страницы сервиса. Это и есть адрес вашего сайта.

## Шаг 3. Проверить сохранение ДО сбора данных

1. Откройте сайт, нажмите «✏️ Изменить данные», поставьте любой объект (приблизьте карту).
2. Вверху должно появиться «✅ Сохранено на сервере».
3. Откройте ссылку в режиме **инкогнито** или на телефоне — объект должен быть на месте.
   Если вверху жёлтая надпись «Данные хранятся в файле» — база не подключилась, данные могут пропасть:
   напишите мне, что видите.

## Шаг 4. Перед отправкой работы: закрыть редактирование

Пароля нет, поэтому до закрытия любой, кто знает ссылку, может править данные (в том числе случайно).
Перед сдачей:

1. Нажмите в редакторе «⬇ Резервная копия» — сохраните файл на компьютер на всякий случай.
2. На render.com откройте сервис `green-pavlodar` → **Environment** → найдите `EDITING_ENABLED`, поставьте `false`,
   сохраните. Сайт перезапустится (около минуты).
3. Теперь все видят данные, но изменить их нельзя. Чтобы снова править, верните `true`.

## Что может пойти не так

* **Сайт «засыпает».** На бесплатном тарифе после примерно 15 минут без посетителей сайт засыпает, и первое
  открытие после паузы занимает около минуты (сайт покажет «Сервер просыпается…»). Если жюри откроет сайт в
  «спящий» момент, придётся подождать. Чтобы сайт не засыпал, заведите бесплатный мониторинг (например,
  UptimeRobot — проверьте его условия), который каждые 5 минут открывает `https://ваш-адрес/api/v1/health`.
* **База живёт 30 дней.** Бесплатная база Render удаляется через 30 дней после создания. Для проверки жюри
  в течение пары дней этого хватает, но создавайте её не слишком рано. Если сайт нужен дольше, скачайте резервную копию
  и загрузите её в новую базу кнопкой «⬆ Загрузить из файла».
* **ИИ-функции.** Без ключа они работают на запасных правилах и шаблонах. Бесплатный настоящий ИИ подключается
  за 5 минут, см. раздел «Бесплатный ИИ» ниже.
* **Тарифы меняются.** Условия бесплатных тарифов смотрите на render.com при регистрации.

## Работа в поле

* Сайт подстраивается под телефон: карта сверху, панель снизу. Кнопка «где я» на карте включает GPS.
* Объекты ставятся только при сильном приближении карты.
* В редакторе выберите объект и нажмите «📍 Поставить в моей точке (GPS)». Сайт покажет точность;
  при ±20 м и хуже лучше ставить вручную.
* Не открывайте редактор в двух окнах одновременно: сайт заметит конфликт и попросит обновить страницу.

## Бесплатный ИИ (Groq)

1. Зайдите на https://console.groq.com, зарегистрируйтесь и в разделе **API Keys** создайте ключ (карта не нужна).
2. На render.com: сервис `green-pavlodar` → **Environment** → **Add Environment Variable**:
   имя `LLM_API_KEY`, значение ваш ключ. Переменная `LLM_PROVIDER=groq` уже задана в `render.yaml`.
3. Сохраните. Сайт перезапустится примерно за минуту.
4. Проверка: откройте `https://ваш-адрес/api/v1/health` — там должно быть `"ai_available": true`.
   Затем нажмите «🤖 Заключение по зоне (ИИ)»: под текстом будет написано «сформировано ИИ» с названием модели.

Если под заключением написано «запрос к ИИ не удался», в скобках будет причина (например, HTTP 401 — неверный ключ,
HTTP 429 — исчерпан бесплатный лимит). Бесплатные лимиты у Groq ограничены (на октябрь 2026 — порядка 1000 запросов в сутки
на модель; актуальные цифры смотрите на console.groq.com), для показа жюри этого достаточно.
Если лимит кончится, сайт не сломается: он вернётся к шаблонным текстам.

Другие бесплатные сервисы (Google Gemini, OpenRouter) тоже подходят: поставьте `LLM_PROVIDER=openai-compatible` и задайте
`LLM_API_KEY`, `LLM_BASE_URL`, `LLM_MODEL` из документации выбранного сервиса.
Помните: на бесплатных тарифах провайдеры могут использовать отправленные данные для улучшения своих продуктов.
В ИИ уходят только названия объектов и посчитанные числа по зоне, ничего личного.
